立ち上げマニュアル

あなたのまちに、
「見守る会」をつくる

まだ見守る会がない自治体で、新しく会を始めたい人のための手順です。特別な知識や肩書きはいりません。どの会も、一般市民がひとりで始めています。

LINEの画面名や配置はバージョンによって変わることがあります。

立ち上げの流れ

  1. 名前と立ち位置を決める

    「〇〇区議会を見守る会」のように自治体名を入れると、検索で見つけてもらいやすくなります。「おしゃべり府中市政」のような独自の名前でもかまいません。

    見守る会に共通するのは「特定の党や人物に肩入れせず、是々非々でカジュアルに政治を語る」姿勢です。管理人の立ち位置を説明欄などで伝えましょう。

  2. ルールを決める（任意）

    ルールを設けるかどうかは自由で、ルールなしで運営している会もあります。使う場合は共通ルールの雛形を自分たちに合わせて書き換えてください。

  3. オープンチャットを作る

    1. LINEの「ホーム」→「オープンチャット」から作成します。
    2. 名前は手順1で決めたもの、説明には会の趣旨（ルールを使うなら短いバージョン）を入れます。
    3. カテゴリは地域・暮らし系を選びます。
    4. 誰でも参加でき、検索で見つかる設定がおすすめです。
    5. このオープンチャット用のプロフィール名を決めて作成します。

    カバー画像は、自分で撮った写真やフリー素材が安心です。

  4. 最初の投稿をする

    ルールを使う場合は、ノートに全文を投稿してアナウンスに固定します。会を始めた理由をひとこと添えると、雰囲気が伝わります。

  5. SNSなどで宣伝する

    X・Instagram・Facebookなどで、自治体名と参加URLを添えて投稿しましょう。「#〇〇区議会」のように自治体名のハッシュタグをつけると、関心のある人に届きやすくなります。知人への声かけや、地域のコミュニティでの紹介も効果的です。

運営を続けるコツ

投稿ネタのアイデア集

  • 次の定例会の日程、傍聴・インターネット中継の案内
  • 議会だよりや会議録で見つけた気になるやりとり
  • 一般質問の通告内容や、議案の採決結果
  • 予算・新しい施設・まちづくりなど、暮らしに身近な話題
  • 地域のニュースや、自治体の公式発表
  • 選挙の日程や、公開討論会・候補者の政策の情報

出典を添えると、事実にもとづいて話す空気ができます。

管理人どうしでつながる

立ち上げたら行動するエンジニア（@angry_engineer0）までXでメンションしてください。一覧に掲載するほか、見守る会ネットワークの管理人専用オープンチャットにご招待します。盛り上げ方や運営の悩みなど、各地の管理人と気軽に相談や情報交換をしましょう。

ルールは必要になったら

困ったことが起きてから、日付をつけて足していけば十分です。文京区の会もそうしてきました。

選挙の前後は、特に中立に

政策や実績を事実にもとづいて話すのはよくても、場として特定の候補を推す形にならないよう気をつけましょう。

無理をしない

合言葉は「ぼちぼち」。議会のたびに少し話題が出るくらいで十分です。
